# 赤雨封鎖線：七日篇

四名成年角色的七日校園感染生存視覺小說，包含小說式敘事、地圖探索、限時 QTE、RPG 討伐、羈絆支線、死亡重試、CG 回放與雙結局。

## 七日流程

- 第一日：落雨與李明朗封鎖圖書館，完成閱覽區、密集書庫與館員室解謎。
- 第二日：兩人趁日照穿越中庭。陰影中的感染者撲倒落雨，玩家須限時連續按對三個隨機按鍵；抵達理化樓前還有第二次伏擊。進樓後，落雨面對昔日同學已成為感染者的事實。
- 第三日：理化系館五樓成為封鎖據點。玩家每天早上只能選擇一位同行者，晚上會與同一人共用值守房；另外兩條羈絆支線會鎖定，不能在同一輪補完。
- 第四日：落雨可提出獨自前往西側舊教學區，但會被三人阻止。只有從這個選擇出發、重新選擇同行者並連續解開環境線索，才有機會偶然抵達沒有標記的舊控制室。
- 第五日：手機完全耗盡，四人搜索西校區並準備離開曾經庇護他們三晚的物理系館。
- 第六日：穿越工程館地下管線，以 RPG 戰鬥處理速度更快的變異者並恢復備用電力。
- 第七日：迎戰會預測人類習慣的 K-01 變異感染者。未取得廣播器時進入四人自行逃離的一般 HE；取得後進入直升機救援與最高羈絆角色的個人未來結局。

## 戰鬥與失敗

- QTE 與 RPG 都會先以紅色閃光、畫面震動和感染者突襲畫面預警，再進入反應階段。
- 每次遭遇要連續按對三個隨機 W、A、S、D；三輪時限依序只有 3 秒、2 秒、1 秒。頂部紅色時間條會快速縮短，按錯或逾時會扣血並把連擊歸零。
- RPG 同時顯示落雨與感染者的血量／階段條，按鍵位置每輪重新排列，鍵盤與觸控按鈕都能操作。

## 解謎與羈絆

- 圖書館三個區域各有三階段線索，須交叉閱讀時間、耗電、聲響與空間資訊；答案按鈕會重新排列。
- 第三日只有被選中的同行者會增加羈絆，且該事件每輪只能觸發一次。
- 舊控制室與通訊設備不會在地圖或目標文字裡標示成隱藏事件，玩家必須從人物選擇及場景暗示自行發現。
